## Learned

- `COMPANY.LOCAL_CURRENCY` is mutable via repeated `INPUT` on the shared company record, same as
  `TRIANGULATION_CURRENCY` — confirmed via Bruno (`COMPANY/proj-field-registry/Create LOCAL_CURRENCY
  field.yml`, no immutability config) and a live-verified example (`15 CO INPUT - Optional
  Triangulation Without Currency.yml`, `LOCAL_CURRENCY` set + `MANDATORY_TRIANGULATION: false` + no
  `TRIANGULATION_CURRENCY` → `200`). This sidesteps the module README's existing "MOCK's own
  `LOCAL_CURRENCY` is test pollution" fragility note — a test can mint and point at its own
  dedicated currency instead of relying on `MOCK`'s ambient value.
- A "discovery test" written against an unconfirmed hypothesis (TC-24) can silently fail to prove
  anything if its precondition doesn't actually exercise the mechanism under test — worth checking
  a discovery test's own setup, not just its assertion, before treating its guessed result as
  settled.
- `qa.proj.local` / `10.0.130.10` is reachable again as of this session (was blocked 2026-08-25) —
  not otherwise exercised this session (no live probe was run; verification stayed static).
