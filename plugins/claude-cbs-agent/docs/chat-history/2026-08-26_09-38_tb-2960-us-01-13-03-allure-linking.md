## Learned

**Durable fact, already routed to `docs/common-issues/allure-testops/allure-story-field-no-id-prefix.md` (new
file) + its `INDEX.md` entry, and to `docs/module-theory/Currency Definition and
Logic/US-01.13.03/README.md`'s new "Allure TestOps linking" section (with the full id mapping
table):** Allure TestOps' `Story` custom field never carries this repo's own `US-XX.YY.ZZ | ` id
prefix — only the bare title. A Story-name filter using the prefixed form silently returns zero
matches even when cases exist, which reads as "not created yet" and can trigger a false escalation.
Always confirm the real stored value on one known case before filtering by Story name.
