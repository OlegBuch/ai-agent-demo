## How to read this document

Each finding has a **Confidence** (High/Medium/Low) and is grouped by **Tier**:

- **Tier 1 — Real duplication, silent-drift risk.** Two or more places independently implement the same rule/shape/value. If one changes and the other doesn't, behavior diverges silently. Fix these first.
- **Tier 2 — Misplacement.** Logic sits in the wrong layer (a "helper" that's really a client, a "client" that's really path constants, etc.), following the same paths/constants/services/helpers/fixtures split TB-2799 already established for `utils/`.
- **Tier 3 — Inconsistency / bad practice.** Naming drift, oversized files, dependency-direction violations — real but lower urgency.
- **Tier 4 — Dead/orphaned code.** Nothing references it; safe to delete once confirmed.
